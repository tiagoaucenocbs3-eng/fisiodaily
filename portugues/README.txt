Para usar em outro site:
1. Copie esta pasta para o projeto.
2. Renomeie se necessário, por exemplo /presell-pt ou /presell-en.
3. Edite o arquivo config.js.
4. Substitua destinationUrl pelo URL final do site/checkout.

Você também pode passar o destino dinamicamente:
/presell/?to=https%3A%2F%2Fexemplo.com%2Foferta

Mas a forma mais simples é editar o config.js.
