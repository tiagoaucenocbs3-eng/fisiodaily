COMO CONFIGURAR O REDIRECIONAMENTO DE WHATSAPP

O sistema agora conta com um REDIRECIONADOR GLOBAL DE MÚLTIPLOS NÚMEROS DE WHATSAPP utilizando Round Robin Atômico (Upstash Redis + Vercel Serverless).

--------------------------------------------------
COMO CONFIGURAR OS NÚMEROS DE WHATSAPP
--------------------------------------------------

1. No ambiente local:
Edite o arquivo `.env` na raiz do projeto:

WHATSAPP_NUMBERS=5511999999999,5511888888888,5511777777777
WHATSAPP_MESSAGE=Olá, vim pelo anúncio e gostaria de mais informações.

2. Na Vercel (Produção):
Acesse o painel do seu projeto na Vercel:
Settings > Environment Variables

Cadastre:
- WHATSAPP_NUMBERS = seus números separados por vírgula (ex: 5511999999999,5511888888888)
- WHATSAPP_MESSAGE = sua mensagem automática em PT-BR
- UPSTASH_REDIS_REST_URL = sua URL REST do Upstash Redis
- UPSTASH_REDIS_REST_TOKEN = seu Token REST do Upstash Redis

--------------------------------------------------
FORMATO DOS NÚMEROS
--------------------------------------------------
Sempre utilize o padrão internacional:
55 + DDD + NÚMERO (somente números)

Exemplo:
5511999999999

--------------------------------------------------
MENSAGEM AUTOMÁTICA
--------------------------------------------------
A mensagem é codificada automaticamente para URLs seguras do WhatsApp, aceitando acentuação, espaços e emojis.

--------------------------------------------------
TESTE LOCAL
--------------------------------------------------
Para testar no seu computador:
npm start
ou
node server.js
e acesse: http://localhost:3000
